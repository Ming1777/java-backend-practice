# Java Backend Practice

这是一个面向 Java 后端实习与校招的个人学习仓库，用于记录 Java 基础、面向对象和算法练习。

## 当前内容

- `day01`：数组与基础遍历
- `day2`：Scanner、类型转换和综合计算
- `day3`：条件判断与菜单练习
- `day4`：循环、质数判断
- `day5`：数组复制、查找与反转
- `day6`：方法、参数与返回值
- `day7`：类、对象与继承
- `day8`：方法重写、多态与类型转换
- `hot100`：两数之和、移动零

## 开发环境

- JDK 17
- IntelliJ IDEA
- Lombok

## 运行方式

1. 使用 IntelliJ IDEA 打开项目。
2. 将项目 SDK 配置为 JDK 17。
3. 找到需要练习的 Java 类。
4. 运行类中的 `main` 方法。

## 学习目标

- 掌握 Java 基础语法和面向对象编程
- 持续练习数据结构与算法
- 后续学习 MySQL、Spring Boot、MyBatis 和 Redis
- 完成可用于实习与校招展示的后端项目
